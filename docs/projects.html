Virtual Brain Inference (VBI)

Probabilistic inference on whole-brain models, from simulation to posterior.

  • Fast simulators in C++, CuPy (GPU) and Numba, spectral, temporal and connectivity features, and deep neural density estimators that recover model parameters from neuroimaging data.
  • Lead developer; published in eLife (2025) and the Journal of Open Source Software (2026), and available on EBRAINS.
pip install vbi

Python, C++, CuPy, Numba, PyTorch, sbi, SWIG

JaxCont

Differentiable continuation and bifurcation analysis in JAX.

  • Follows equilibrium and periodic-orbit branches through folds, and detects fold, Hopf, branch-point and period-doubling events.
  • The whole sweep compiles with jit, batches with vmap and differentiates with grad, so bifurcation points can be optimised directly.
  • Checked case by case against MatCont 7.6 and BifurcationKit.
pip install jaxcont

Python, JAX, Matplotlib, pytest, Sphinx

lyapax

Lyapunov exponent spectra of ODEs, maps and delay equations, written natively in JAX.

  • Pushes tangent vectors through your own step function with jax.jvp and vmap, so no Jacobian has to be derived by hand.
  • Handles fixed-delay equations and partial spectra, whose cost grows with the number of exponents tracked rather than the system size.
  • Runs unchanged on GPU; benchmarked against ChaosTools.jl and jitcode.
pip install lyapax

Python, JAX, Diffrax, pytest, Sphinx

LitForge

A local-first desktop app for finding, screening and writing from scientific literature.

  • Turns a DOI, a few keywords or a reference list into a ranked reading list from OpenAlex, Crossref and arXiv, with the reason each paper was found.
  • Parses each PDF once into sections, figures, tables and equations, so a language model reads only what a question needs; quoted answers are checked against the source page.
  • Includes a LaTeX writing studio with live preview and one-line installers for macOS, Linux and Windows.

Python, PyMuPDF, Docling, local and cloud LLMs, Typer, Tectonic

LitForge Source and install LitForge User guide

MD Viewer

A Markdown viewer for mixed Persian and English text, with LaTeX math.

  • Each paragraph, heading and table cell takes its direction from its own first letter, so bilingual notes read correctly.
  • Ships as one offline web page, a desktop app for macOS, Windows and Linux, and an Android app on Cafe Bazaar.

JavaScript, marked, KaTeX, highlight.js, DOMPurify, Tauri
